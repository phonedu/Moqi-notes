# 功能与概念（五件事）

墨契（Moqi）是一个**大纲 + 双链**的本地笔记：所有内容都是「块」，页面就是块树，页面之间用 `[[双链]]` 相连。理解它只需要五个概念：

| 概念 | 一句话 |
|---|---|
| **块 Block** | 一行内容（正文 / 待办 / 标题 / 引用 / 代码 / 图片 / 附件 / 嵌入），可无限缩进成大纲 |
| **页面 Page** | 一棵块树；页面名 = 正文第一行，允许重名 |
| **双链 Wiki link** | `[[页面名]]` 连到另一页；`((引用))` 引用某页 |
| **属性 Property** | 页面级键值（文本 / 数字 / 日期 / 选项），全局定义、本页取用 |
| **标签 Tag** | 页面级分类；正文里的 `#标签` 可在导入时收编为页面标签 |

## 已实现（v0.7.0）

- 大纲编辑：缩进 / 折叠 / 拖拽排序 / 多选批量操作 / 撤销重做
- 双链与反链：`[[ ]]` 自动补全建议、反链面板、引用预览
- 检索：中文子串 + 拼音（多音字按词库）、⌘K 全局搜索、页内查找
- 属性与标签：全局属性定义、选项集、筛选面板
- AI 助手（自带 key，OpenAI 兼容接口）：总结 / 提取行动 / 问答（带来源）/ 润色 / 扩写
- 图片 / 附件 / 嵌入块；导入 Markdown（含 Obsidian zip）、导出 Markdown / 整库
- 代码块：标语言、块头下拉/自由输入、非编辑态轻量着色（注释 / 字符串 / 数字 / 关键字）、一键复制源码
- 表格：默认网格编辑（点格改字、加行加列、删行删列、列对齐）、合并单元格、拖表头调列宽；源码视图随时切回
- 同步读数与回滚：设置里写清上一轮「合并 / 跳过 / 失败」；上一次有写入的同步可在当次会话内整段回滚
- 诊断日志：本机技术日志（启动 / 告警 / 崩溃现场）＋埋点读数＋操作日志，一键导出成一份纯文本，不含正文
- 主题 20 套（明暗两态）、排版三轴可调
- 桌面（Windows）+ Android；一套交互两种形态

## 明确不做

账号 / 云服务 / 多人协作 / 插件 API / 全局图谱 / 主题商店 / 完整语法高亮引擎（AST / 补全）/ 块级属性界面。完整清单见 [ROADMAP](ROADMAP.md)。

## 已知边界（诚实清单）

- **表格 / 公式**：表格以标准 Markdown 表格存正文，网格编辑是真编辑器；合并单元格与列宽写在表格下方一行隐藏注释里（别的编辑器只看到普通表格）。块级公式仍是源码显示，不做公式渲染
- **同步**：块级合并、后写者胜；合并 / 跳过 / 失败的读数在设置里可见。整段回滚只覆盖「上一次有写入的同步」且限当次会话——重启后要逐条撤销。首启默认页与很早以前的历史根块没有同步日志，其内容不会跨端（新建页面正常）
- **Android 打包**：当前提供 debug 构建说明，release 签名流程待发布批
