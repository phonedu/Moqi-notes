# Roadmap（可能做 / 不做）

**以下没有排期承诺，也不做承诺**——维护者按自己的使用与证据决定做不做、何时做。

## 正在做

- 公开发布整备（文档 / 构建脚本 / 清洗）
- 真实使用反馈的收集与分级（GitHub Issues）

## 可能做（有登记、看证据）

- **同步完整性**：首启默认页 / 很早以前的历史根块补上同步日志（让首屏内容也能跨端）；同步历史面板
- **编辑器块专项**：表格改真实块节点（高度随内容、不再靠上限压后面正文）、代码块编辑态着色与行号、公式渲染
- **页面库多选**：批量删除 / 导出 / 加标签；**页面合并**（块树拼接、引用重指向）
- **查找替换**、**块引用↔粘贴自环修复**、**AI 上下文结构化**
- 统计页（多端一致性自检视角）
- release 签名打包流程（Android / Windows 安装器）

## 不做

账号 / 登录 / 云服务 · 多人协作 · 插件 API · 全局知识图谱 · 主题商店 · 代码高亮渲染 · 块级属性界面 · 脚注块 · 块锚点 `^ID` · 页面别名系统 · 软换行

> 「不做」不是傲慢：每一条都是为了守住「五个核心概念」与本地优先的边界。除非真实使用给出强证据，否则不重开。
