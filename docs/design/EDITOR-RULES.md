# 编辑器规则编号系统（术语表）

墨契的代码注释里引用了大量规则编号——它们是开发过程沉淀的**决策索引**，公开仓库保留编号以便追溯。这份术语表解释编号体系本身；每条规则的具体内容在内部开发仓，公开面按「代码即真相」理解。

| 前缀 | 含义 |
|---|---|
| `R04-*` | 编辑器稳定规范（输入 / 光标 / 名字行 / 撤销等编辑器行为契约） |
| `R09-*` | 界面与交互规范（桌面 UI / 移动端 / 导出 / 同步等的界面契约） |
| `D-数字` | 偏差台账（发现的问题 → 归因 → 修复 → 验收 的记录） |
| `T-数字` / `θ编号` / `G-编号` / `W-编号` | 阶段工单 / 线框稿 / 缺口账 / 骑批工单 |
| `PAGENAME-*` / `MOBILE-*` / `R09-EXPORT-*` 等 | 验收项 ID（自动化验收脚本里的断言名） |

两条最有用的入口：
- **数据与行为契约**：`packages/editor/src/domain/` 的模块注释
- **验收脚本**：`app/scripts/accept-editor.mjs`（214 项浏览器级断言，每项名字即行为 ID）
