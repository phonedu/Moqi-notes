# 上手指南

## 第一次启动

1. 安装后打开即是页面库（首页）
2. 右下 **＋** 新建第一页 → 直接输入页面名（就是第一行）
3. `Enter` 建下一块，`Tab` 缩进成子级——大纲就这么长出来

## 常用动作速查（桌面）

| 动作 | 入口 |
|---|---|
| 全局搜索 | `⌘K` / `Ctrl+K`（支持拼音） |
| 页内查找 | `⌘F` |
| 双链 | 输入 `[[` 弹候选；`((` 引用某页 |
| 图片 / 附件 | 斜杠菜单 `/` 或粘贴截图、拖入文件 |
| 代码块 | 斜杠菜单 `/代码`；块头徽标选语言（也能自己输入） |
| 表格 | 斜杠菜单 `/表格`，或直接粘贴 / 导入 Markdown 表格 |
| 折叠侧栏 | `⌘\`；页面列表 `⌘⇧\` |
| 专注模式 | 顶栏 … 菜单 |
| AI 助手 | 顶栏 ✦（需在设置里填 OpenAI 兼容 key） |

## 手机上

- 首页 = 页面库卡片；左滑卡片出现多选；双击块进编辑
- 键盘上方是格式栏；选中文字弹气泡（复制 / 粘贴 / 格式）
- 顶部 ← 返回页面库；⋯ 更多（查找 / 统计 / 导出）

## 代码块与表格

- 代码块：块头语言徽标点开即选（设置 → 外观 →「代码块语言」里可勾选常用语言，也能自由输入任意语言）；不点进去时按注释 / 字符串 / 数字 / 关键字上色，点进去就是纯文本编辑；块头「复制」复制的就是源码原文
- 表格：默认是网格——点格改字、「＋ 行 / ＋ 列」、行尾列尾删除、表头右缘拖动改列宽；Shift 点选多格可「合并」，选中合并块可「拆分」；右上角「源码」随时看 Markdown 原文。合并与列宽会记在表格下方一行隐藏注释里，别的编辑器只看到普通表格

## 同步（可选）

设置 → 同步：选一个本地目录（推荐放云盘同步盘）。两台设备都指向它即可块级合并。设置页会写清上一轮「合并 / 跳过 / 失败」；上一次有写入的同步可以点「回滚到同步前」整段撤回（当次会话内有效）。现状与注意事项见 [DATA](DATA.md) 的「同步现状」。

## 出问题要看日志

设置 → 诊断 →「导出诊断日志」会生成一份纯文本（技术日志＋埋点读数＋操作日志），只写编号 / 计数 / 耗时与错误码，**不含正文**，可以直接发给人排查。
