# 数据在哪、怎么带走

## 存储位置

- 桌面（Windows）：`%APPDATA%/com.moqi.projectb/`（Tauri 应用数据目录）
- 单文件 SQLite 库 `project-b.sqlite3` ＋ `assets/`（图片附件，文件名不透明化随机 id）＋ `snapshots/` ＋ `exports/`

## 备份与带走

- **自动快照**：每日 / 每周保留策略（7 日 + 4 周），本地同盘
- **整库导出**：设置 → 备份与恢复 → 一键导出 `.zip`（库 + assets），可作恢复源
- **Markdown 导出**：单页 / 按标签 / 全量；属性与标签写入 YAML front-matter；图片随 `assets/` 打包
- **导入**：`.md` 拖进正文即建页；`.zip` 包恢复；行内 `#标签` 可选收编为页面标签

## ⚠️ 换机器前必读（重要）

**整库 zip 与快照会把「设备身份 + 同步游标」一起带走**（存于库内 `app_metadata`）。把 zip 导入另一台机器，两台设备会以同一身份往同步目录写日志，可能互相覆盖。换机器的正确姿势：**新机器先完成首次同步配置后再恢复内容**；或在导出 zip 前确认旧机器不再使用。此边界将在后续版本于导入边界自动处理。

## 同步现状（诚实声明）

- 同步 = 本地目录（云盘同步盘）上的块级合并，后写者胜；双端实测通过
- 已知缺失：合并结果不弹提示、跳过项不重试、被覆盖版本仅当次会话可撤销。详见 [ROADMAP](ROADMAP.md) 的「同步反馈面」批次
