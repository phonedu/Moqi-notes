# FAQ

**许可证为什么是两层的（应用 AGPL / 编辑器 MPL）？**
墨契应用的立身之本是「你的数据你带走」——任何改进版（包括托管成网络服务）都必须同样开源，所以应用用最强的 **AGPL-3.0**。而 `@moqi/editor` 编辑器包用 **MPL-2.0**（按文件级别的弱 copyleft）：其他项目——包括闭源应用——都可以把它当依赖使用，只有直接修改编辑器的文件才需要公开改动。应用守底线，编辑器广传播，两条都要。

**会有账号 / 云同步吗？**
不会。同步 = 你自己选的本地目录（可放云盘同步盘），数据永远在你手里。

**收费吗？**
软件本体免费开源（应用 AGPL / 编辑器包 MPL-2.0）。不做订阅、不做功能墙。

**为什么手机优先？**
「要双链、又要手机上能用」是这个项目的起点——桌面双链工具很多，手机上能日用的大纲双链几乎没有。

**能导入 Obsidian 吗？**
能。Markdown / zip 都支持，保真边界见 [MIGRATION](MIGRATION.md)。

**数据在哪、会不会被锁住？**
本地 SQLite 单文件 ＋ assets 目录；导出为标准 Markdown 与整库 zip。宪法三条底线之一：**数据能导出带走**。

**AI 功能必须联网吗？**
AI 是可选功能且自带 key（调用你选的 OpenAI 兼容服务）；不用 AI 完全不影响编辑 / 检索 / 同步。
