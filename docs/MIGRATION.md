# 从其他工具迁来

## 从 Obsidian

- 把 vault 里的 `.md` 拖进墨契正文即建页；或打包成 zip 批量导入
- YAML front-matter 的标签 / 属性会被读取
- 行内 `#标签` 默认收编为页面标签（导入页有开关）

### 保真边界（导入时会发生什么）

| Obsidian 语法 | 墨契行为 |
|---|---|
| `[[链接]]` / `[[页\|别名]]` | 保留为双链 / 显示文字 |
| `![[页面]]` | 转页面嵌入块；目标页缺失时占位悬空（不丢内容）；同包内目标排在后面也会在导入结束时补链 |
| `![[图片.png]]` | 图片块，文件按相对引用落地 |
| `- [ ]` 任务 | 待办块（含勾选态） |
| `> [!note]` Callout | 降级为引用 ＋ 首行原文（不丢内容） |
| ```` ```js ```` 代码块 | 代码块，**保留语言标记**；块头徽标可选 / 改 / 清除语言；导出按 ` ```js ` 写回。轻量着色只在应用内显示，导出不进文件 |
| 表格 | 存为 Markdown 表格块；默认网格编辑（点格改字 / 加减行列 / 对齐 / 合并 / 列宽），右上角切源码；导出逐字节还原。合并与列宽写在表格下方一行隐藏注释里，别的编辑器只看到普通表格 |
| `$$…$$` 块级公式 | 公式源码块，导出原样；应用内按源码显示（不做公式渲染） |
| `$行内公式$` | 行内文本，源码保留 |
| `%%注释%%` | 应用内隐藏内容、光标可穿行编辑；导出原样写回 |
| `[^1]` 脚注 / `^块ID` / aliases | 字面保留 / 不支持（既定边界） |
| 上标 `^x^` / 下标 `~x~` | 按上标 / 下标渲染，导出原样写回 |

## 从幕布 / Logseq

幕布导出的 Markdown 直接可入；Logseq 按其 Markdown 方言按上面的边界降级。

## 从墨契导出走

「我们 → 我们」最可靠：设置 → 备份与恢复 → 整库 `.zip`，到新机器「从备份包恢复」。注意换机器前必读 [DATA](DATA.md) 的设备身份说明。
