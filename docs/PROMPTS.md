# 内置 AI 提示词

AI 助手七条指令的系统提示词唯一真源 = `packages/editor/src/editor/../..`（实际位置：`packages/editor/src` 内由 `app/src/adapters/ai.ts` 消费的 `SYSTEM_PROMPTS`——见该文件）。这里列出七条指令各自做什么：

| 指令 | 行为 |
|---|---|
| 总结 | 中文简洁总结，只输出正文 |
| 提取行动 | 每行一个可执行项，无编号 |
| 反问我 | 针对内容提 3 个引导深入的问题 |
| 润色 | 保留原意调整表达 |
| 扩写 | 补细节不引入新事实 |
| 换角度 | 换立场 / 读者 / 时间尺度重写 |
| 有来源问答 | 只依据给定正文回答，答不出明说 |

共同口径：只输出正文、不加前言（结果直接落成块）；未采用的 AI 输出一律整块不导出。
