# 其他扩展语法

上标：x^2^，下标：H~2~O。

高亮：==重要内容==。

Emoji 短代码：:smile: :rocket: :+1: 。

定义列表（部分实现支持）：

术语
: 定义内容

缩写（部分实现支持）：

*[HTML]: Hyper Text Markup Language

The HTML specification.

注释（部分实现支持）：

%%这是隐藏注释%%

Critic markup（部分实现支持）：{++新增++}{--删除--}{~~替换~>新~~}。

任务列表扩展：

- [ ] 未完成
- [x] 完成
- [-] 取消（扩展）
- [/] 进行中（扩展）

HTML 注释与 Markdown 混排：<!-- 注释 --> 之后还有文字。
