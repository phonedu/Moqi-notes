# 更新日志

本文件是墨契（项目 B）每个交付版本的用户可见变化，格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

分类固定为五个：新增 / 改进 / 修复 / 数据与兼容 / 已知限制。条目每个一行，只写用户能感知的结果，不写文件名和任务编号；任务编号、验收步骤和证据见 `docs/07-验收记录.md`（总入口）与当前阶段的 `docs/07-<阶段>-验收记录.md`。版本号与阶段号（V1 / V2a / V2b / V3）的对应关系见 `docs/05-版本状态与计划.md`。

## [0.6.1] - 2026-10-26

修复与打磨（PATCH）：手机编辑交互的十处回修 ＋ 编辑器包的复用收口（无新功能）。

### 修复

- **拖拽放置线读不出落点**：改为独立于块的整横线（两端翘头，落在目标间隙正中）；「放入其内」= 左缘竖轨——不再像给块描框。
- **当前页卡的边框**：全卡 1.5px 主题色边框（深色模式同样可见、随主题变色）——替换左缘 2px 色条。
- **页面标题三个观感问题**：与顶栏的距离收窄；占位文字与输入后的标题完全同位（不再「输入后缩到下面」）。
- **删光标题后再按 Backspace 不再顶乱正文**：空标题行上是页面边界，正文不再被顶下去一行。
- **手机 ⋮ 菜单先小后大**：面板高度随视口即时修正（键盘收起时不再出现两段式变化）。
- **AI 报错看得懂了**：透传服务端原话（如「模型不存在」）＋ 按错误类型给检查指引；出厂不再写死模型名，服务方改模型名无需等应用更新。
- **手机格式栏**：「列表与段落」面板只留图标；选择栏「＋插入」再点一次收起；多选「待办」二次点击整批转回正文；编辑时页面随光标 / 键盘滚动；「拍照」在安卓壳如实禁用（指路相册——壳层暂不能拉起相机）。
- **复制 / 复制为块引用有反馈了**：按键瞬时变 ✓（0.9 秒还原）。
- **命中区补齐**：编辑页顶栏图标纽与卡片标题「打开」行的可点范围扩到 ≥44px（视觉不动）——紧凑档触控目标再无例外。

### 改进

- **编辑器包（开发者）**：触控交互层（格式栏 / 块胶囊 / 选择栏 / 选区气泡 / 拖拽放置线 / 键盘高度）并入 `@moqi/editor` 包；app 全量走公开 API；`MoqiEditor` 修三个运行时问题（换文档重挂载 / 落盘串行队列 / 错误边界）；补包内测试。

### 数据与兼容

- 无数据格式变化；SQLite 表结构未变，0.6.0 库直接打开。

### 已知限制

- 「拍照」需要安卓壳层改造（相机意图），登记后续原生批。
- 平板两轴仍在 0.7。

## [0.6.0] - 2026-10-26

阶段 V3 · 移动端专项触控交互。**手机端从「能看」到「能日用」**：页面库、编辑、导入导出、备份恢复与属性区在手机上完整可用；桌面窗口缩到手机宽度直接预览同一套版面。含两轮预发布修复（回收站外键、侧栏统计）。

### 新增

- **手机端完整可用**：首页页面库、侧栏抽屉、卡片菜单 / 回收站 / 设置 Sheet、底部安全区适配；桌面窗口可缩到手机宽度，直接预览同一套版面。
- **手机端编辑**：左滑多选、块胶囊 / 选择栏、批量缩进与上下移动、插入块 Sheet、键盘上方六键工具栏、选区气泡格式。
- **手机端导入导出**：通过系统文件选择器导入 Markdown / 备份包、导出 Markdown / 整库备份；剪贴板改用原生实现，复制在真机可用。
- **备份与恢复**：从 `.zip` 备份包恢复；恢复快照或备份包前先确认，替换动作不再事后通知。
- **属性区重设**：属性统一为全局属性；本页可添加 / 删除属性行，「从本页删除」保留值；标签、属性、时间收在一张表里。
- **编辑与阅读**：断点体系与窗口自适应；代码块内 Enter 换行；多行无记号粘贴按行拆块；移动工具栏图标化。
- **侧栏统计**：近 12 周页面活跃热力图 ＋ 页面 / 标签 / 字数三格；数字 ≥1000 简写（`1.2k` / `1.2万` / `1.2亿`），悬停仍能看到精确值。

### 改进

- **桌面与手机统一减法**：顶栏收成一行；页面卡片压到 128px、两行摘要、不再展开；设置从九项收到四组；手机底栏撤掉，改用顶栏编辑 / AI 入口。
- **日常操作不再弹成功提示**：成功由界面自证；失败就地显示；删除、恢复、合并、丢弃 AI 块等不可逆动作改为事前确认。
- 侧栏、搜索、AI 面板、回收站、空态与占位文案精简；浅色 / 深色主题与新三栏色带保持一致。

### 修复

- 手机状态栏遮挡顶栏、☰ / 设置点不到；底栏被系统手势条遮挡。
- 手机工具栏点按后编辑器失焦；复制按钮在 Android WebView 报权限错误。
- 手机图片 / 附件灯箱与插入面板越界；批量删除偶发静默失效。
- **回收站彻底删除不再报「保存失败」**：页面进回收站前删过的子块会一起清理，不再撞数据库外键；失败时页面原样保留，图片不会被提前清掉。删除改为先落盘、后更新界面。
- 彻底删除当前打开的页时自动切到下一张，不再停在已删除的页。
- 多选删除、块引用、页面名行等一批触控与键盘边缘问题。

### 数据与兼容

- `Block` 新增两个可选字段 `propertyShown` / `propertyHidden`（属性面板本页的显示 / 隐藏偏好）。旧版本不认识这两个字段，打开与编辑不受影响；回滚到 0.5.0 后这两个显示偏好不生效。
- SQLite 表结构未变；0.5.0 的库可直接打开，不需要迁移。0.6 新增的原生剪贴板与 Tauri 2.12 插件轮不改数据格式。
- 统计是派生数据，不落盘、不进同步。

### 已知限制

- **真机走查剩余项与「真机日用三天」**（F 清单的人工手感项）并入开源计划 P1「真实试用与回修」窗口收口；机械面读数与两项收口裁决已落档 `docs/07-V3-验收记录.md`。
- **触控命中区两处已知例外**：编辑页顶栏图标纽（宽 36–38px，高度已达标）、页面卡标题「打开」行（高 34px、整行可点）——补齐排 0.6.1。
- 平板两轴未实现（无安卓平板，规格保留，排 0.7）；同步冲突留档、单页历史等仍在待审 / 触发点观察区。

## [0.5.0] - 2026-10-08

阶段 V3 前半「带得走」。**人工验收于 2026-10-08 关闭**（清单 A–E；证据见 `docs/07-V3-验收记录.md`）。

这一版把「带得走」补起来：**数据和图片附件能一起打包带走，别的工具也能读**；顺带把界面收拾成三栏色带、主题可换、排版可调。

### 新增

- **图片与附件**：菜单 / 粘贴截图 / 拖入三条路都能放进正文；图片可点开大图（缩放、另存副本），附件显示文件名与大小并可另存。
- **嵌入块**：把另一页或某个块嵌进来，只读显示它的内容、跟着源更新；点「来源 ↗」跨页跳过去，源被删则降级成「来源已删除」。
- **导入 Markdown**：把 `.md` 拖进正文就建出一页（连它的 `assets/` 图片附件一起落进来）；对不上的链接与缺文件如实说明、按文字保留，不丢字。
- **导出保真**：Markdown 导出把标题层级、列表、待办、引用、双链、属性与标签都写进文件；图片附件进 `assets/` 一起打包；嵌入块展开成引用块快照。
- **一键导出整库**：导出一个 `.zip` 包（`project-b.sqlite3` + `assets/`），换机器 / 留档时带走；路径直接显示出来。
- **主题与排版**：20 套主题（每套含浅色与深色）、正文字号 / 行高 / 列宽三轴可调，随调随生效。
- **外部链接三入口**：斜杠菜单 / `⌘L` / 格式栏「链接」，也可直接粘贴网址；`[[页面|显示文字]]` 支持别名（只影响显示）。

### 改进

- **三栏工作区改成三条色带**：侧栏 / 页面库 / 编辑区各有底色、交界没有多余竖线，换主题只换颜色不换位置。
- **常驻格式栏可折叠**，块操作收进 `⋯` 与右键菜单（两份是同一份清单）；块可 `⌘⇧↑/↓` 上下移动。
- **页面标题与属性条之间的距离收窄**（此前空得发慌）。
- **删除前看得见「谁在引用我」**：删被引用的块或页面时提示「N 处引用」并可一键撤销。

### 修复

- **高亮真正存进数据**（此前打完 `==高亮==` 重开就没了）。
- 停止生成中的 AI 内容、块级复制剪切、退格删除等一批编辑器边缘问题。
- 输入框统一成控件外观（此前多处是浏览器默认的黑线，聚焦时还会出现两条线）。

### 数据与兼容

- **新增三种块类型**：`heading4` / `heading5` / `heading6`（四级到六级标题）——**旧版本不识别这三种类型**，用旧版本打开会按普通文本显示（数据不丢，向上兼容）。
- **新增两个数据目录**：`snapshots/`（本地快照）与 `exports/`（导出落点）；**新增 `assets/`**（图片与附件本体）。回滚到旧版本 = 旧版本忽略这三个目录，数据不受影响。
- **块数据格式未变**：只多了一个可选的 `asset` 字段（图片 / 附件的载荷），旧版本读它是空值。
- **整库导出产物从 `.sqlite3` 改成 `.zip`**（含 `assets/`）；单份快照导出仍是裸 `.sqlite3`（快照本就不含资产）。
- 导入是**只进不出**的：0.5 不提供「把导出的包放回去」的入口（恢复走快照列表）。

### 已知限制

- **Android 真机路径未验**（快照 / 恢复 / 导出在设备上的形态）。
- **「系统另存为」顺延**：导出落在数据目录 `exports/` 并把路径显示出来；系统对话框要引插件、会连带升级框架，单独一轮做。
- **导入只认通用 Markdown**：针对幕布 / Obsidian / Logseq 各自导出格式的适配等拿到真实样本再做。
- 每日快照**不含**图片附件（快照之后又被彻底删除的文件不在其中）；要连资产一起带走用「导出整库」。

## [0.4.0] - 2026-10-05

阶段 V2c「智能检索和建议」。**人工验收已于 2026-10-05 关闭**（桌面 A–G 组、Android 真机 F 组、L 类门槛都走完；**其中 E3「提示词质量」一项经用户裁决豁免**——理由与记录见 `docs/07-V2c-验收记录.md`）。

这一版把「找回来」补起来：**搜索能搜中文、也能打拼音**，页面库能筛，写 `[[` 时有建议，还能拿检索结果直接问 AI。

### 新增

- **全局搜索（⌘K；手机上走侧栏「搜索」行）**：按中文子串搜页面、块与标签，结果分组、点一条跳到那一块并闪烁定位；两字词也搜得到。
- **拼音检索**：打 `yinhang` 或 `yh` 都能命中「银行」——多音字按词库判断（不会拼成 yinxing），中文原文检索照旧。
- **页面库筛选面板**：星标 / 标签（含所选 · 排除所选）/ 时间范围 / 属性 / 关键词 / 反链 + 排序，选中即生效，触发按钮带条件数徽章。
- **双链建议**：写 `[[` / `((` 时，候选菜单底部按规则给建议（已引用本篇 / 同标签 / 标题含… / 都引用了《…》），每条只给一个理由；接受才写入。
- **有来源问答**：从 ⌘K 把检索命中的块交给 AI 助手当范围提问，回答带来源（点一下跳回原文）。面板头部写明**答案存到哪**（当前页 / 新建一页），插入按钮上也写着落点。
- **AI 指令四项补齐**：润色 / 扩写 / 反问我 / 换角度接上真实动作（与总结、提取行动一起共六项可用）。

### 改进

- **设置里新增「检索索引」卡片**：引擎、索引规模、上次重建、拼音覆盖、写入失败——降级看得见。
- **索引状态如实显示**：空块与纯标点块不再被算成「拼音没建」（此前覆盖率会永远差几块，而且每次开机重算全库）。
- **`[[` 候选菜单**：同一个页面只出一行，但理由不再因为去重而丢失（例如「已引用本篇 · 空页面」）。
- **AI 助手的范围与落点分开写**：输入行写范围、头部写落点；从检索进来时不再默认说「基于本篇」。

### 修复

- **页内引用本篇不再可能**：此前一篇页面的正文块能引用它自己，结果这一页的反链面板会把自己算成来源。
- **打开页面库后 AI 面板点不动**：修掉面板的层级，并规定「同一时刻只留一个覆盖层」——开面板自动收起抽屉、开抽屉自动收起面板。

### 数据与兼容

- 检索索引重建过两次（拼音列、拼音覆盖标记）：**老库升级后由启动时自动回填，不涉及数据迁移**；块数据格式没有变化。

### 已知限制

- Android 版仍是 Debug 构建（未签名，装机会有系统风险提示）。
- 手机上记的内容目前**没有**同步到共享目录的路径（手机上写的暂时只在那台手机上）；导出在后续版本。
- 四项 AI 指令的**提示词质量**尚未用真实模型评过（本地 stub 只验证过链路）——见 `docs/07-V2c-验收记录.md` 的豁免记录。

## [0.3.0] - 2026-10-03

阶段 V2b「同步与第二端」。**人工验收已于 2026-10-03 关闭**（桌面清单 A/B/E、真实云盘目录上的双窗口同步 C 组、Android 真机 D 组均已走完并有记录，见 `docs/07-V2b-验收记录.md`）。

这一版把三件事补齐：**页面能标星与置顶**、**回收站能真的删干净**、**两台设备能通过一个共享文件夹同步**。Android 壳也在这一版落地（能装、数据层与同步命令都在，触控交互留到后面的版本）。

### 新增

- **页面星标**：卡片 ⋯ 菜单与编辑器 … 菜单都能标，两处是同一份数据；标过的页面卡片头部出现 ★，点它即可取消。星标只做标记，不影响排序。
- **页面置顶**：卡片 ⋯ 菜单置顶，置顶的页面排在页面库与页面列表的最前面，并在卡片头部显示「已置顶」。**最多置顶 5 个**，满了菜单会置灰并说明；打开软件时默认进入的是置顶页。
- **回收站「彻底删除」与「清空回收站」**：从本机彻底删除会清掉正文、页名与子块，且不可恢复；动手前先列出「哪些页面将失去指向本页的双链」。
- **回收站到期自动清理**：放满 30 天的条目会在下次打开软件时自动从本机彻底删除，并给出提示。
- **同步**：在设置里填一个**文件夹**（放在云盘或局域网共享目录里，两台设备都指到它）即可同步；侧栏底部显示状态——已同步 / 同步中 / 离线空闲（N 条待同步）/ 未配置。同步在后台自动进行，每 10 秒拉一次对端的改动。
- **Android 版**：这一版开始有 Android 壳，数据存储与同步能力与桌面版一致。

### 改进

- **保存状态搬到编辑器顶栏**（页内查找、页面大纲、更多三个按钮的左侧）。它回答的是「这一篇存住了没有」，跟页面走、写字时一眼可见；侧栏底部那一格让给了同步——那是全应用共用一条队列的状态。
- 侧栏底部的状态行可以点开进设置。
- 设置里的「同步」卡片从占位说明变成真实配置：同步位置、立即同步、当前状态、本机设备标识。

### 修复

- **同步：对端写的改动现在能被拉取**。此前只有自己落盘才会触发同步，于是「配好同步但自己不再编辑」的机器永远看不到另一台写的东西——而换台机器接着写正是同步的用途。
- **同步：对端新建页面时的正文不再丢**。此前页面能同步过来、内容是空的。
- **同步：对端的改动会刷新你正打开着的那一页**。此前内容进了库、页名也变了，但正打开的正文一动不动（要重开这一页才看得到）；此时在本机接着写，还会把对方那一版覆盖回去。
- **回收站 30 天保留期现在是真的**。此前界面显示「剩余 N 天」，但到期不会有任何清理动作。
- **重启后回收站不再变空**。此前软件只载入未删除的块，回收站里的页面在下次打开软件时就从界面上消失（内容还在库里，但没有任何入口能恢复它）——「到期自动清理」也因为同一原因一次都没真正跑过，现在会按时执行。
- **同一台设备不再出现两个身份**。全新安装的头一分钟里，同步可能给这台机器生成两个设备标识，表现是共享目录里多出一份属于同一台机器的日志文件；现在一个库只有一个身份。

### 数据与兼容

- **块结构新增两个字段**：星标与置顶。都有默认值，打开旧库时会自动补齐为「未标星、未置顶」——**旧数据不会丢，也不需要手动迁移**。
- **回滚**：用旧版本打开新库会忽略这两个字段，正文与结构完好；但置顶与星标的状态会丢失。
- **回收站语义变化**：这一版起，「彻底删除」会真的从本机数据库里删掉整棵子树（此前只能软删除与恢复）。删掉的内容不在回收站里、也不可撤销。
- **同步的变更日志不进数据库结构**：它用了库里本来就有的两张表，不需要为此迁移；日志不参与备份与导出。

### 已知限制

- **「彻底删除」只作用于本机**。其他设备上的副本不会被远程抹掉；等同步功能支持多端之后，那边的副本会移入那边的回收站，由那边的你决定。要彻底清干净，需要在每台设备上各删一次。
- **变更日志里仍保留被删页面的正文**。它是本机的运行日志、不对外传输，也不会在回收站或界面里出现，但确实还在数据库文件里。
- **同步的冲突判定比的是两台设备的时钟**。两边几乎同时改了同一段内容时，由时间较晚的一方覆盖；**两台设备时钟偏差较大会影响结论**。
- **取消置顶后不一定回到最初的位置**。置顶期间如果新建或移动过页面，取消后它会落在当时的位置上。
- **Android 版目前只有壳**：能安装、能读写数据、能同步，但触控手势与移动端布局（键盘上方格式栏、底部操作栏等）留到 0.6.0。
- 同步位置需要自己填、自己保证两台设备指的是同一个文件夹；没有账号，也没有云端服务。

- 桌面人工验收查出并修复：页面标题点不进去——刚点进标题就被弹回正文，改不了名字。根因是编辑器插件的注册在每次界面刷新时重跑一遍（Lexical 的节点转换注册会触发一次编辑器更新），那次更新会把焦点抢回正文。现在插件只注册一次、回调取最新值，标题可以正常点进去改名，改完立刻反映到页面库与侧栏。另外：标题里按回车提交、按 Esc 取消，光标都会直接落在正文第一块（提交后可以接着写；取消不会把临时改的名字写进去）。

- 桌面人工验收查出并修复：行尾 ＋ 连续插块之后重开软件，整篇编辑器会变成只读——缩进 / 反缩进 / 行尾 ＋ / 转换块类型全部没反应，只有字还能敲进去（而且什么都不会存下）。原因是插入新块时只把新块写进库、没写「父块的子级清单」，重开时数据里的父子关系对不上，之后每一次写入都被校验拒绝。现在「谁动了父子关系，谁就一起落盘」由数据层自动记账，不再依赖每个写入点记得补父块；打开旧数据时也会自动把漏记的块收回原位并提示修复结果。
- 桌面人工验收查出并修复：输入文字后按 ⌘Z 撤不掉刚敲的字，反而把更早的结构动作（缩进 / 类型转换等）撤掉了。原因是撤销归属在判断「编辑器那边还有没有可撤的内容」时问了一个 Lexical 旧版历史插件根本不回答的查询命令，于是每次 ⌘Z 都被送进结构历史。现在改成「先按最后那次改动的归属去撤，撤不动才换另一套」：敲字后 ⌘Z 撤字、⇧⌘Z 重做；结构动作后 ⌘Z 撤结构、⇧⌘Z 重做同一个结构动作。
- 桌面人工验收查出并修复：在正文块末尾按回车没有反应（新建不了新块），原因是编辑器与数据在「删块后撤销」这一串动作下会分家，随后所有结构操作（回车 / 缩进 / 转类型）都被同一个错误拦住。现在两边任何一侧多出或少掉块都会自动收敛（编辑器撤回来的块会重新写回数据），回车与结构操作恢复正常。

- 桌面人工验收查出并修复：拖拽块后松手即取消（此前会按最后一次悬停的位置落位）；点击 `[[页面链接]]` / `((块引用))` 跨页面时可正常打开目标页面并定位到目标块（此前无反应）。
- 桌面人工验收查出并修复：折叠子树的 ⌘↑ / Ctrl+↑ 生效（点块左侧折叠箭头一直可用）；悬停块时界面不再反复重渲染。
- 桌面人工验收查出并修复：保存失败不再静默——会提示失败原因，且失败期间的新编辑会继续落盘（此前可能只留在内存里，重载后丢失）；被校验拒绝的写入不再把数据留在半提交状态（此前会出现「界面还能用、但什么都写不进去」）。
- 桌面人工验收查出并修复：AI 生成中途退出后残留的「生成中」块会自动收口为完成或已停止，生成期间的「停止」入口不再消失。
- 桌面人工验收查出并修复：AI 块的操作条点不到——它此前是长在块外的浮动条，且只在鼠标悬停块时出现，鼠标移向它时悬停态先失效，条子比指针先消失。现在按原型把两条行放进块里：块内顶部是「AI 生成 / AI 生成中」与操作、来源标签（生成中还有 ■ 停止 与三点动画），块内底端是虚线分隔的操作条（✓采用 / ↻重新生成 / ✕丢弃 / 💬继续追问）。两条行常驻显示、不需要悬停；块本身仍是普通正文块，点正文即可继续编辑。
- 桌面人工验收查出并修复：反缩进会把正文块挤出本篇——顶层正文块按 ⇧Tab 曾被当成「提到顶层」，块先掉到页面末尾，刷新后整块从页面与页面库消失。现在顶层正文块按 ⇧Tab 不再有任何变化（页面容器不算一级缩进）；拖拽同样不能把正文块拖成页面之外的新根。
- 桌面人工验收查出并修复：缩进到标题下的正文比正文粗、项目与编号列表还会变成标题那么大——缩进后的块会继承「上级块类型」的排版属性（标题的 700 字重与 24px 字号、代码块的等宽与不折行、引用与勾选待办的弱化色）。现在每个块自己声明字族、字号、字重、行高、空白处理与颜色，上级块不再影响下级块的观感。
- 桌面人工验收查出并修复：按 Tab / ⇧Tab 之后焦点会被浏览器带走——⇧Tab 把焦点交给页面标题并把正文滚回顶部（看起来就是「整页抖动、跳到最前面」），Tab 把焦点交给块把手、之后敲键盘写不进正文。现在光标在块里时 Tab / ⇧Tab 一律由编辑器处理（包含「无处可缩进」的情形），光标不在块里或正在用输入法时仍然交给浏览器。
- 桌面人工验收查出并修复：缩进 / 反缩进 / 转换块类型之后光标会跳到那段开头（写完一句再缩进，接着打字就插到段落最前面）。现在光标留在原处，缩进后接着打字仍然落在你刚才的位置；只有光标不在被操作的块里（用块工具栏处理别的块、多选）时才回到段首。
- 桌面人工验收查出并修复：斜杠菜单与 `[[` 候选菜单不跟随滚动——菜单打开后滚动正文，菜单会停在原处。现在两个菜单都跟着光标块走；斜杠菜单在「光标不在该块文字末尾」时也能弹出（比如在已有文字前面输入 `/`）。
- 桌面人工验收查出并修复：两个工具栏的 `[[` 页面链接按钮不生效——它会在文字中间插入触发词，而候选菜单此前只认「触发符在行尾」，于是菜单不弹、正文里只留下一截 `[[`。现在触发符可以在块内任意位置：选中文字 → 点 `[[` → 选目标页面 → 这段文字变成双链，光标停在链接之后。
- 桌面人工验收查出并修复：正文里按 ⌘Z 可能撤掉你刚敲的字，而不是刚做的结构动作（缩进 / 转换块类型）——敲进去的字被同时记进了两套撤销历史，且撤销后光标会跳到页面最开头。现在一次 ⌘Z 撤销最近的结构动作、正文完整保留，光标留在原来那个块里。
- 桌面人工验收查出并修复：刚回车或刚点行尾 ＋ 新建的块，在写回数据之前对缩进 / 反缩进 / 转换类型是「死键」（按了没反应）；用 ＋ 插入的空块还可能落到本块上面。现在这些操作会先把新块落到数据里再执行。
- 桌面人工验收查出并修复：行内格式（加粗 / 斜体 / 删除线 / 行内代码 / 高亮）此前只有加粗看得见——斜体、删除线像是没生效，格式也没法叠加（加粗 + 高亮 / 加粗 + 斜体只显示一个），行内代码没有等宽底纹、高亮是浏览器的纯黄。原因是编辑器没有把格式交给样式渲染（Lexical 一个文本节点只画一个标签）。现在五种格式各自可见、可以任意叠加，样式与页面库等处的行内样式一致。
- 桌面人工验收查出并修复：三个工具栏各说各话——顶部格式栏的格式按钮完全没有按下态，块工具栏的按下态比操作慢一拍。现在三层各自管好自己的作用域、共用同一份格式状态：**块工具栏管整个块**、**选中文字后的工具栏管选中文字**、**顶部格式栏与格式快捷键（⌘B / ⌘I / ⌘⇧S / ⌘⇧H）管文字选区与「接下来输入的字」**（点一下开启、再点一下取消，按钮会亮），三个地方亮起的格式始终一致。
- 编辑器块级交互按稳定规范重建：把手、行尾 ＋、折叠箭头、待办复选框都跟随块的真实位置，输入或换行后不再停留在旧位置；空页面不再出现多余的折叠控件，也不能被整页收起；折叠箭头只属于标题块（H1/H2/H3）。四种控件都可用键盘操作并带可访问名称。
- 新建 / 重命名 / 复制页面时名字自动去重（「未命名页面」→「未命名页面 2」…），不再出现「保存失败：UNIQUE constraint failed」；历史遗留的重名页面在打开时自动编号并提示。
- 转换块类型（格式栏 Aa ▾ 或斜杠菜单「转换为」）不再清空正文，行内格式与引用一并保留；斜杠菜单只丢弃触发词。
- 打开或新建页面后光标直接落在第一个正文块，不再出现「直接打字却写不到块里、没有把手、刷新后内容不属于本页」的情况。
- 页面库卡片不再互相顶高：展开某一张不会带动整排（此前整排一起变高，看起来像全排都展开了）；属性行与反链行固定贴在自己的内容下方，不再出现卡片中间悬空一大块。
- 页面库卡片的「展开 / 收起」入口按真实内容溢出判断，不再时有时无。
- 页面库只保留「列表 / 简约」两种形态（画册在三栏里退化成单列卡片、与列表没有差别，已移除）：**画册**（网格浏览）、**列表**（一页一张卡，四段信息齐全，可就地展开看全文）、**简约**（紧凑三行，一屏看更多页）；卡与卡之间留出间距，展开与收起固定在卡片右下角同一位置。
- 图标统一换成 **Lucide**（ISC 协议，可自由商用与再分发）：菜单、搜索、把手、面板、格式栏等全部图标换成官方图形，风格更整齐。
- 页面库只保留「侧栏 + 页面库栏 + 编辑区」三栏工作区一种形态，去掉整屏页面库与其入口（侧栏「页面库」回到工作区）。
- 编辑器左侧新增**页面列表**：点列表里的页面在右侧就地打开，不跳视图；⌘⇧ 折叠/展开这一列，⌘ 折叠侧栏，两列都折叠就是放大写作；⌘N 随时新建页面。
- 撤销路径统一：正文里按 ⌘Z 会先撤销刚做的结构动作（转换类型、缩进、折叠、勾选等），再撤销敲进去的字；重做（⇧⌘Z）同样可用。此前结构动作会被字符撤销顺带回滚，撤销一次可能连带吃掉文字，重做有时没有反应。
- 桌面人工验收查出并改进：一次 ⌘Z 只会撤销一套历史——此前按一次可能同时动了结构和光标位置（撤销后光标会跑到块内别处）。现在撤销严格按「谁记的最后一次改动就撤谁」，撤销结构动作后光标精确回到原来的位置。
- 桌面人工验收查出并修复：选中文字后点 `[[` 转页面链接「没反应」——选中的文字被当成了搜索词（选中普通词就一个候选都没有），而且选定目标后链接文字会被换成页名；此外编辑器与数据的同步有时差，抢着选候选还会静默失效或把原文复制一份。现在：选中文字 → 点 `[[` → 候选列出**全部页面**（不受选中文字限制）→ 选目标后**选中的原文原样成为链接文字**，正文不多不少；光标处直接输入 `[[` 仍是「边打边筛、用页名当链接文字」。
- 桌面人工验收查出并改进：`((` 块引用候选的标签与提示——空块不再显示 `(空 Block)`（显示「（空块）」）、页面容器显示页名，右侧提示显示**所属页面**而不是内部编号。
- 窗口尺寸不再改写侧栏设置：此前把窗口拖过窄屏断点会改写并保存「侧栏是否折叠」，手动折好的侧栏会被一次拖窄再拖宽重置回来。现在窗口宽度只决定呈现——窄屏下侧栏是覆盖式抽屉且默认不弹出（点标题栏 ☰ 展开、点遮罩收起），侧栏的开合设置只在你点击开关时变化。
- 窄屏下两个抽屉不再互相带起：在侧栏抽屉里点「新建页面」会顺带把页面列表的抽屉拉起来（而且要手动关掉它）。现在窄屏新建页面会收起侧栏抽屉、不打开页面列表；在页面列表抽屉里点开一张卡，抽屉也会自动收起，不再压着刚打开的正文。
- 关闭窗口前先落盘：此前关窗直接销毁界面，落盘节拍（600ms）内、以及还没同步进数据的字会丢。现在点关闭、Alt+F4、任务栏关闭和系统关机都会先把编辑器里还没同步的字写回并等保存队列落盘，然后才关窗；有 AI 块正在生成时先弹确认（继续生成 / 直接关闭）。
- 按规范自查发现并修复：AI 生成会把每一步流式增量都记进撤销历史——生成完之后按 ⌘Z，AI 块只是短一截，不是被撤掉（实测 60 个流式节拍留下 61 条记录，一次 ⌘Z 只退回 4 个字，要按 61 次才撤得掉一次生成）。现在一次 AI 生成只占一个撤销步：⌘Z 一次撤掉整块，⇧⌘Z 重做把完整正文带回来。
- 按规范自查发现并修复：「提取行动」生成的行动项此前要撤两次（第一次只撤掉程序内部的生成占位块）——现在结果与占位块同属一次生成，撤销一次即整批退掉。
- 按规范自查发现并修复：「继续追问」的提示语与实际行为不符（写着「已把该 AI 块作为上下文」，实际提问基于整篇内容）——提示语已改准。
### 数据与兼容

- 数据落点：桌面端为单机 SQLite（Tauri），浏览器预览为 localStorage；本版本不含同步，没有跨设备数据。
- 数据格式与 0.1.0 兼容，旧数据无需迁移，本版本没有破坏性 schema 变更。

### 已知限制

- 图谱、全局搜索、筛选面板、导出、历史快照和媒体块只保留入口位置并标注版本，尚未实现。
- 同步、局域网直连与设备列表属于 V3，设置页中为占位说明。
- 正文里手写的 `#标签` 是普通文字：不识别、不渲染、不登记、不计入标签（行内标签已裁决不做，口径见 `docs/09` §十三）；标签只作为页面级系统字段维护。
- **AI 块的文字在滚动页面时可能有轻微上下抖动**（用户 2026-09-28 实测；幅度小、不影响操作，暂按可用接受）。已修掉两处确定的原因（滚动时每帧重复写块高预留值、界面头部没压住覆盖层），仍有残余抖动未定位；现象、已排除项与下一步排查方向见 `docs/07-V2a-验收记录.md` 同日记录。
- V2a 的 9 项桌面人工验收已在真实 Tauri 窗口执行并通过（步骤、证据与结论见 `docs/07`）。仍未覆盖：真实操作系统中文输入法的候选窗与上屏手感（本轮用输入法事件接口验证）、长文档下的拖拽手感与大文件性能、剪贴板动作（复制链接 / 复制页面）。
